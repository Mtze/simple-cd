# 0009 Hand-placed draw.io diagrams for structural views

- **Status:** Accepted
- **Date:** 2026-11-20

## Context

The first PlantUML component and deployment diagrams were laid out automatically and had crossing lines and labels on lines.

## Decision

Object model, component, deployment and service specification diagrams are generated by `docs/architecture/uml/diagrams.py` with fixed coordinates through a small draw.io DSL. Sequence, activity and state diagrams stay PlantUML, because their layout follows the order of the source and does not suffer from those problems. This deliberately deviates from using one tool for all diagrams.

## Consequences

Changing a structural view means editing coordinates and checking the preview. Contributors need the draw.io CLI for structural views and Docker for the dynamic ones.
